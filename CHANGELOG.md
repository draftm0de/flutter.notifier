# Changelog

All notable changes to this project are tracked here. This file follows the
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/) convention.

## [0.1.1] - 2024-05-28
### Added
- DraftModeNotifier with built-in YES/NO workflows, notification tap buffering, and consumer registration helpers.
- `DraftModeNotifierConfig`, enabling localized action labels alongside unit coverage for defaults and `copyWith`.
- A Cupertino sample that wires customizable text fields into actionable notifications for easy manual testing.

### Changed
- README and inline docs highlight the sample, dialog bridge, and auto-generated notification ids so first-time integrators can follow along without extra boilerplate.
